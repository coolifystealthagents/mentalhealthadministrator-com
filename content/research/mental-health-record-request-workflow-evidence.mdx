## A source-controlled measurement model

| Layer | Definition | Evidence |

## Define denominators before calculating rates

For record request controls, a percentage is interpretable only when readers know which records were eligible and excluded. Separate unavailable evidence from confirmed failure. Keep duplicate records visible during reconciliation, then explain the deduplication rule used for reporting.

For record request controls, measures should not combine unlike states. Sent is not delivered, delivery is not comprehension, administrative completion is not clinical suitability, payer receipt is not payment, and transfer is not resolution. Report each state according to the source evidence available.

## Preserve provenance and corrections

For record request controls, store the source, effective date, capture time, worker, procedure version, and any external reference number beside each material value. When sources disagree, preserve the conflict and route it. A later correction should not erase what staff relied on earlier.

For record request controls, use stable identifiers but minimize copied sensitive information. The operational report should contain what its purpose requires, not clinical narrative added merely to make a status seem more explanatory.

## Sample quality without clinical overreach

For record request controls, select a documented sample that includes routine records and known exceptions. Compare administrative fields with their named sources, check that statuses satisfy definitions, and confirm protected decisions reached qualified or authorized owners.

For record request controls, do not score clinical judgment through an administrative audit. Suitable measures include source agreement, required-field completeness, correct queue routing, documented attempts, explicit uncertainty, closure evidence, and correction traceability.

## Governance and access controls

For record request controls, name owners for the procedure, source inventory, access roles, templates, status definitions, exception queue, measurement specification, and remediation log. The same person may hold several roles, but responsibility should not be implicit.

For record request controls, use individual accounts, least privilege, periodic access review, controlled exports, and documented offboarding. A technical login does not expand a worker's professional authority.

## Seven-step audit procedure

1. Confirm the current purpose, population, procedure, and owner.
2. Freeze the sample rule and eligible reporting period.
3. Compare recorded facts with the named authoritative sources.
4. Recalculate statuses, numerators, denominators, and exclusions.
5. Verify protected questions were transferred without interpretation.
6. Classify errors by process cause and assign remediation.
7. Retest the affected control after the change takes effect.

For record request controls, observed changes can coincide with calendar supply, demand, staffing, policy, payer behavior, system configuration, communication preference, or definition changes. Before-and-after values alone do not establish cause.

## Frequently asked questions

### Does this framework make a clinical decision?

For record request controls, no. It measures administrative states and controls. Clinical assessment, urgency, diagnosis, treatment, and level-of-care decisions remain with qualified practice personnel.

### Can a completed field be treated as verified?

For record request controls, only when the measure defines verification and records a comparison with the named source. Completion alone proves neither accuracy nor professional approval.

### How should unknown information appear?

Keep it explicitly unknown, name the requested source and owner, and show the next review date. Do not fill the gap with an assumption.

### Does this review certify regulatory compliance?

No. A practice should obtain appropriate legal, privacy, security, payer, and contractual guidance for its circumstances.

## Conclusion

For record request controls, defensible record request controls uses declared populations, authoritative sources, observable states, explicit exclusions, protected role boundaries, and traceable corrections. Transparent methods are more valuable than a broad score whose underlying records cannot be reconstructed.
