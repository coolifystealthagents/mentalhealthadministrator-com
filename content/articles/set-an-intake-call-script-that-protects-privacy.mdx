## How to approach: Set an intake call script that protects privacy

An intake call script should gather what the practice needs without collecting more than necessary. Start with the caller's name, the reason for the call, and the best callback number. Do not ask for clinical detail before the caller is verified. Keep the original note beside the corrected version.

Keep the script short enough to use during a real call. A long form read aloud feels impersonal and slows the intake. The receptionist should be able to move through it naturally. Write the deadline as a date and a local time.

## Verify the caller and the purpose

Ask whether the caller is the client, a guardian, or a professional. The answer determines what information can be shared. Record the relationship and the callback number. A short note with four fields is easier to use than a long narrative.

Explain the practice's privacy practice in plain language. Do not promise confidentiality beyond the law or the practice policy. The script should name the limits without alarming the caller. Name the owner in the same line as the action.

## Collect the minimum information

Collect the information needed to schedule or route the call. A clinical history is not needed at the front desk. The receptionist should record the reason in the caller's words and route the clinical question. Record the exception and the person who approved it.

Record the preferred language and any accommodation. A caller who needs an interpreter should not have to repeat the request at every step. Update the template when the same question appears twice. A short note with four fields is easier to use than a long narrative.

## Route the clinical question

If the caller asks for advice or a diagnosis, the receptionist should record the question and route it to the clinical team. The script should not invite the receptionist to answer. Ask whether a new reviewer could act on the record without a conversation. A control that depends on memory is not yet a control.

Record the time and the person who received the question. A question that is not routed will return as a complaint. Test the rule on one real call before applying it to the queue. A short note with four fields is easier to use than a long narrative.

## Review the script with the team

Ask the front desk and the clinicians whether the script collects the right information. Remove a question that is never used. Add a question that would prevent a callback. Ask whether a new reviewer could act on the record without a conversation.

Keep the script with the intake record. A later review may need to see what the caller was told. The goal is a respectful intake, not a longer form. Keep the original note beside the corrected version.
