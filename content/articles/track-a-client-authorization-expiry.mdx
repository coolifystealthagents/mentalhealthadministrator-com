## How to approach: Track a client authorization expiry

An authorization tracker should show what is approved, how much is left, and when it expires. Start with the service, the units, the expiry, and the next review. A tracker that only lists the end date hides the risk. Separate what was observed from what was assumed. The practice should review the wrong-route calls monthly. Keep the tracker current. A session that is delivered after the expiry may not be billable. Keep the evidence with the record rather than in a separate log. ## Record the authorization and the units

Write the authorization number, the service, the units, and the dates. Record the source and the reviewer. A number without the approved units is incomplete. Keep the boundary visible in the place where the work is assigned. The front desk should record the caller's relationship before sharing any detail. The authorization should be checked before the session.

Record the units used and the units remaining. A remaining balance without the source is a guess. A control that depends on memory is not yet a control. ## Set the reminder and the owner

Send a reminder before the expiry. Name the person who will request the renewal. A reminder without an owner is a notification. Test the rule on one real call before applying it to the queue. The practice should keep the clinical question with the clinical owner. The authorization should be checked before the session.

Record the renewal request and the response. A pending renewal should have a date. Review the first few notes together before the process expands. Record the date and the source so the next reviewer can repeat the check. The review should end with one owner and one date. A note that cannot be reconstructed later is not a control.

## Review the tracker weekly

Look for a client who is close to the unit limit or the expiry. Assign an owner and a date. A missed renewal may delay care. Name the owner in the same line as the action. The records release should name the authority and the scope. The practice should review the wrong-route calls monthly.

## Review the process quarterly

Look for a payer with a slow renewal or a repeated denial. Update the tracker and the reminder. Keep the original note beside the corrected version. Name the owner in the same line as the action.
