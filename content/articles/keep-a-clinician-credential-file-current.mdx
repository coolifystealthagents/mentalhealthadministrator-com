## How to approach: Keep a clinician credential file current

A clinician credential file should show that the license and the required training are current. Start with the license, the expiry, the evidence, and the review. An expired license is a serious risk. A short note with four fields is easier to use than a long narrative. The practice should keep the clinical question with the clinical owner. The team should test the script with a real call type.

Keep the file in the approved system with restricted access. Write the deadline as a date and a local time. Use the same format for every handover so the next reader can scan it. Keep the original note beside the corrected version. The practice should keep the clinical question with the clinical owner. The review should end with one owner and one date.

## Record the license and the expiry

Write the license number, the issuing body, and the expiry. Attach the certificate or the verification. A number without the evidence is weak. Record the exception and the person who approved it. The team should test the script with a real call type.

Record the required training and the expiry. A training that is not recorded may be assumed. If the source is unclear, route the question instead of guessing. Separate what was observed from what was assumed. The records release should name the authority and the scope. The practice should keep the clinical question with the clinical owner.

## Set the reminder and the owner

Send a reminder before the expiry. Name the person who follows up. A reminder without an owner is a notification. Keep the evidence with the record rather than in a separate log. The authorization should be checked before the session. The client's preference should be recorded and followed.

Record the renewal and the new expiry. A renewal that is not recorded may trigger a false alert. Test the rule on one real call before applying it to the queue. Review the first few notes together before the process expands. The practice should review the wrong-route calls monthly. The team should test the script with a real call type.

## Review the file quarterly

Compare the file with the schedule. Look for a clinician scheduled with an expired credential. A mismatch is a finding about the process. Ask whether a new reviewer could act on the record without a conversation. The authorization should be checked before the session. The client's preference should be recorded and followed.

## Keep the file after the clinician leaves

Retain the record according to the policy. A later audit may need it. Name the owner in the same line as the action. Keep the boundary visible in the place where the work is assigned. The practice should keep the clinical question with the clinical owner. A note that cannot be reconstructed later is not a control.
