## How to approach: Plan a weekly practice operations review

A weekly operations review should answer one question: which items need a decision this week, and who will make it. Everything else belongs in the written queue. If the meeting reviews every call, it becomes a status report. Keep the evidence with the record rather than in a separate log. The practice should review the wrong-route calls monthly. The records release should name the authority and the scope.

Choose the items before the meeting. The practice manager should select the blocked, aging, or client-sensitive items. Send a short evidence pack in advance. Name the owner in the same line as the action. The schedule change should be checked against the room and the billing. The records release should name the authority and the scope.

## Prepare the evidence pack

For each item, include the request, the source, the open question, the owner, and the next step. Keep it to one page. A pack that takes an hour to read will not be read. Review the first few notes together before the process expands. The records release should name the authority and the scope. The team should test the script with a real call type.

Do not include the entire history. Link the relevant records and summarize the rest. The purpose is a decision. Use the same format for every handover so the next reader can scan it. ## Review by next action

Group the items by the decision they need: schedule, billing, records, or clinical review. This turns a list of tasks into a list of decisions. It also shows when one person is the bottleneck. For each group, ask what would change the current position. If nothing would change it, the item may not need a meeting slot. If the source is unclear, route the question instead of guessing. Ask whether a new reviewer could act on the record without a conversation. The review should end with one owner and one date. A note that cannot be reconstructed later is not a control.

## Limit the meeting to decisions

Do not read updates that everyone already has in writing. Ask the decision maker for a choice, a condition, or a request for specific evidence. Record the answer in the queue.
