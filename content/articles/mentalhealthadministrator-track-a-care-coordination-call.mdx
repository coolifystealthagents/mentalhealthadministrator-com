## How to approach: Track a care coordination call

In the care coordination call workflow, a care coordination call arrives before anyone confirms the client, the period, or the responsible queue. A care coordination call case without a named owner is treated as unassigned, even when a document is already attached. Every care coordination call case carries a stable reference before the call record or the participants is attached. The care coordination call handoff begins with a named receiver and ends only when that receiver accepts the case in the care log. The care coordination call working file joins the call record, the participants, the action items, and the reviewer on one case reference so the decision can be rebuilt. A care coordination call request can be complete and still not be approved, so the note separates the request from the decision. A care coordination call case that crosses a shift keeps the original requester visible beside the new owner. Review pass 1.2: the practice administrator files the care coordination call evidence.
