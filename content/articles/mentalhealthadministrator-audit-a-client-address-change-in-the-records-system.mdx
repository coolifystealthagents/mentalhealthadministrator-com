## How to approach: Audit a client address change in the records system

In the client address change workflow, a client address update arrives before anyone confirms the client, the period, or the responsible queue. Every client address change case carries a stable reference before the change request or the identity note is attached. The client address change case begins when a client address update reaches the queue and stays open until the records supervisor records a decision in the client record. Review pass 1.1: the practice administrator files the client address change evidence.

The client address change working file joins the change request, the identity note, the old address, and the update timestamp on one case reference so the decision can be rebuilt. A client address change request can be complete and still not be approved, so the note separates the request from the decision. If two client address change sources disagree, the note says which system of record will govern the answer. Review pass 1.2: the practice administrator files the client address change evidence.

## Confirm the change request and the identity note

The client address change review compares identity note with update timestamp and lists the records that cannot be joined. When the old address is missing, the gap is flagged with a reason in the client address change file. A client address change status update points to a verifiable event in the client record, not to a feeling about progress. A null client address change result is published beside a positive one, using the same definitions and exclusions. Every client address change value is linked to the field in the client record that supports it. The original change request stays beside the correction so the client address change history cannot be rewritten. ## Set the decision boundary for the records supervisor

The records supervisor approves a client address change exception, while the preparer records the evidence and the time of the handoff. No deadline widens the client address change authority beyond the scope written in the case template. The records supervisor owns the client address change decision; the assistant may prepare, compare, and route but not approve. The client address change reviewer can see who approved, what they approved, and when the approval expires. Review pass 3.1: the practice administrator files the client address change evidence.

The client address change authority note names the records supervisor as approver and records any delegation with its end date. When client address change changes the client record, the preparer and the approver remain separate roles. A client address change exception above the written limit goes to the records supervisor before any dependent action continues. The client address change authority limit is written into the template with its scope, amount, and expiry. Review pass 3.2: the practice administrator files the client address change evidence.

## Record and release the exception

When the address changes without an identity check, the client address change case pauses until the client record shows a corrected value and a named releaser. When the address changes without an identity check, the dependent action stops and the conflict is logged in the client record. A repeated client address change exception becomes a reason code rather than a story retold in each thread. Review pass 4.1: the practice administrator files the client address change evidence.

The client address change queue marks a paused case with the reason it stopped and the person who can release it. A client address change exception without a releaser is treated as open, even if the workaround already ran. The client address change queue marks the exception with its age so a second occurrence is easy to find. The failed client address change attempt stays with the correction so the cause remains visible. Review pass 4.2: the practice administrator files the client address change evidence.

## Review the client address change pattern

The client address change review ends with one change, one owner, and a date to re-measure the same population. The client address change review separates ordinary, reopened, missing-evidence, and cross-owner cases. Open client address change items are reported by age and dependency because a stable total can hide an aging tail. A client address change pattern is described before it is called a trend, and outliers are explained at case level.
