# CARDINAL RULE: Protect truth, visitor trust, and build integrity

## Heartbeat checklist

1. Scan rendered copy for prohibited dashes, pricing, speed claims, unsupported proof, and parent brand terms.
2. Confirm every commercial CTA points to `/contact-us`, includes `Free`, and has a valid CTA id.
3. Confirm form behavior, preview noindex, sitemap exclusions, schema, and route health.
4. Confirm only the approved analytics script and booking iframe are present.
5. Run `npm test`, `npm run qa`, and `npm run build` before handoff.
6. Do not publish, deploy, commit, or create remote side effects without explicit approval.
